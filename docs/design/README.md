## 見た目の方向（食材のいろ。ADR-093）

**墨と紙の色で組み、食材の3色（トマト・青菜・卵黄）は献立のカードにだけ大きく使う。見出しは極太の丸ゴシック。**
地は生成りの紙の色、文字は墨に近い黒。

- **色の面は献立のカードにだけ使う。** カードはトマト → 青菜 → 卵黄 の順に回し、色で3件を見分けさせる（意味は持たせない。意味は文字が運ぶ。NFR-17）。カードの外で食材の色が出るのはロゴの3つの点だけ（下の「色の規則」）
- **見出しの書体（`M PLUS Rounded 1c` 900）は大きな文字にだけ使う** — 画面の題・カードの名称・帯の見出し・主の操作・ロゴ。本文・欄・補助の文字は本文の書体のまま
- **線は文字色の 2px で引く** — 入力欄の枠、副の操作の枠、見出しの下の線。区切り線だけは 1px の `--color-border`
- **帯（下タブ・サイドナビ）は文字色の地で、選択は面の色の 4px の線** と文字の太さで示す

## 色の規則（ADR-093）

色は増やすほど安く見え、どの色が意味を持つのかも読めなくなる。**色は役割ごとに置き場所を決め、置き場所の外では使わない。**
新しい画面や部品も、この表のどれかに当てはめて色を決める。

| 役割 | 色（トークン） | 置いてよい場所 |
| --- | --- | --- |
| 墨と紙 | 地・面・線・文字の色（`--color-background` 〜 `--color-text-on-dark`） | すべて。操作・帯・選択・焦点・進行線・見出しの線・案内の帯は、状態を知らせるものを除いてこれだけで組む |
| 食材の色 | トマト・青菜・卵黄（`--color-fill-*`） | **献立のカードの面**（1枚に1色）と**ロゴの3つの点**だけ |
| 状態の色 | 赤・黄土・緑と、それぞれの薄い地（`--color-danger` / `-caution` / `-positive` と `-surface`） | 状態を知らせる文字・アイコン・小さな印・線・薄い地。**赤の地（塗り）は取り消せない操作（削除）にだけ** |

1. **画面の大部分は墨と紙で組む。** 主の操作は文字色の地に面の色の文字、副の操作は文字色の 2px の枠。選んでいること（下タブ・サイドナビ・履歴の切り替え・補完の一覧）は、面の色の線・地の反転・控えめな面・文字の太さで示し、色を足さない
2. **食材の色は献立を指す色である。** 献立のカードとロゴの点のほかに置かない — 見出しの飾り・手順の番号・履歴の行・操作・帯・案内の帯にも使わない。カードの中の文字と部品（札・矢印・線）は、カードの色・面の色・文字色だけで描き、ほかの食材の色や状態の色を混ぜない
3. **状態の色は、その状態のときだけ出す。** 赤は今日まで・不足・失敗・断り・削除、黄土は期限が近い、緑は賄える・在庫が変わった・作ったことがある。広い面には塗らず、文字・線・薄い地で知らせる（赤の地は削除の操作だけ）
4. **色だけで意味を伝えない**（NFR-17）。状態には文字かアイコンを必ず添える。カードの色は3件を見分けるためのもので、意味を持たない
5. **トークンに無い色を作らない。** 地と文字の比は 4.5 以上にする。足りない色が出てきたら、トークンの表と ADR を直す話にする

実装の前にユーザーの了承を取る**（2026-09-29 のユーザー指定。プロジェクトの運用の指示「機能を追加する際は着手前に確認する」）。**2026-10-02、ユーザーが4つとも答えた**（「決定」の列）。
