# icons

**ここは画面ではない。** `features/` が画面の置き場であるのに対し、ここは**どの画面からも引く部品**である。
アイコンは下タブ（`navigation/`）・献立・在庫・設定のどれもが使い、**どれか1つの `features/` には置けない**
— `features/meal/` に置けば、在庫の画面が献立の画面を import する形になる。`navigation/` を
`features/` の外に出したのと同じ置き方である（`navigation/README.md`）。

**層を1つ増やしたのではない。** `docs/adr.md` A章 の表は `apps/web/` をまとめてプレゼンテーション層に
対応づけている。ここもその内側である。

| ファイル | 役割 |
| --- | --- |
| `Icon.tsx` | アイコンの部品 `Icon`。原本 `docs/design/src/Icon.dc.html` の11個（設計 B-59 3章）と、献立のカードの `forward`（`back` の向きを返した形。ADR-093） |
| `Icon.module.css` | 置き方（行の中で浮かせない・縮ませない）。色も寸法も持たない |

## ここで守ること

- **形は原本をそのまま写す。** `viewBox="0 0 24 24"` と path を変えない。形を詰めるのはデザインの側
  （ADR-093 決定2）。原本に無いアイコンは `docs/design/README.md` に書いた形で足す（ADR-093。
  今は `forward` だけで、`back` と同じ線で向きを返した形）
- **色を持たない。** 線も塗りも `currentColor` で、置き場の文字色に従う。`more` だけは塗りで線なし
- **線の太さは大きさから導く。** `1.5 × 24 ÷ size` を小数2桁に丸める（原本の `sw`）。大きさを変えても
  描かれる太さが 1.5px 相当に保たれる
- **アイコンは飾りである**（設計 B-59 6章 規則5 / NFR-17 の構え）。`aria-hidden="true"` で読み上げから
  外し、名前は置き場の側（文字・`aria-label`）が持つ。**アイコンだけの操作には置き場の側で
  `aria-label` を付ける** — アイコンが名前を持つことはない
- **用語表の語で名づける。** 名前は原本の `options` のまま（`meal` `pantry` `history` …）で、禁止語を使わない。
  原本に無い `forward` は `back` の対の名前である
- **見た目の値（形・線の太さ・寸法）は単体テストで見ない**（ADR-055 決定3）。テストが観るのは役割の無さと
  名前の扱いだけである
